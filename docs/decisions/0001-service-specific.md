# 0001 汎用基盤ではなく、このサービス専用の構成で始める

日付: 2026-10-13

## 決定

クラスタと共通サービス（Argo CD・監視・S3）も含めて、このリポジトリ1つに持つ。
汎用のプラットフォームとして切り出すのは、2つ目のサービスを載せるときにする。

## 理由

- 利用者が1つしかない段階で汎用部分を設計しても、何が共通かは当て推量になる
- 汎用化は「上から包む」ではなく「共通部分を下へ抜き出す」作業になる。抜き出しやすさは今の習慣で決まるので、次の3つだけ守る
  1. `infra/`（入れたもの）と `databases/`・`cmd/`（作ったもの）を混ぜない
  2. Traefik・StorageClass などクラスタ全体の設定を DB のマニフェストで書き換えない
  3. DB の namespace には必ず ResourceQuota / LimitRange を付ける（12GiB の機体で DB を守るため）
